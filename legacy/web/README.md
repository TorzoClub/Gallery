# Torzo Gallery Web

当前活动前端，包名 `torzo-gallery-web`，包含公开相册和 `/admin` 后台。

## Scripts

| 命令 | 作用 |
|---|---|
| `pnpm dev` | 启动 Vite 开发服务器 |
| `pnpm build` | 类型检查后构建 |
| `pnpm build:only` | 跳过类型检查直接构建 |
| `pnpm preview` | 预览构建产物 |
| `pnpm typecheck` | TypeScript 类型检查 |
| `pnpm lint` | ESLint |

安装、环境变量、代理和部署见根目录 [README.md](../README.md) 与 [docs/configure.md](../docs/configure.md)。
